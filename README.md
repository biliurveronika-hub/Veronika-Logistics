## Навчальна платформа

Вхід по пошті без пароля: ученицю додає Вероніка в адмінці, ученица отримує
лист із посиланням. Прогрес, домашні завдання та коментарі викладача
зберігаються в Supabase.

- `learn/index.html` — вхід
- `learn/app.html` — кабінет: прогрес, 9 модулів, відео, презентації, домашні
- `learn/admin.html` — адмінка: додати ученицю, прогрес кожної, перевірка робіт
- `learn/assets/config.js` — **єдиний файл із налаштуваннями** (Supabase, Bunny)
- `learn/assets/course.js` — програма курсу: назви, пункти, тексти домашніх
- `learn/supabase.sql` — схема бази, виконати один раз у Supabase SQL Editor

Прогрес рахується по трьох кроках у кожному модулі (відео → презентація →
домашнє). Крок потрапляє в знаменник лише тоді, коли матеріал уже завантажено,
тому відсотки не залежать від того, скільки уроків іще не залито.

Поки `SUPABASE_URL` порожній, платформа працює в демо-режимі: дані лежать
у `localStorage` браузера відвідувача.

Відео — Bunny.net Stream, вбудовуються по GUID з `course.js`.
Захист від скачування — Allowed Referrers у налаштуваннях бібліотеки Bunny.

⚠️ Репозиторій публічний. Усе, що лежить у `learn/materials/`, може завантажити
будь-хто, хто знає адресу. Платні презентації краще тримати в Supabase Storage.

Покрокова інструкція з налаштування — у файлі `НАСТРОЙКА-ПЛАТФОРМЫ.md`
в робочій папці проєкту.

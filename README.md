# Veronika Logistics — комерційна пропозиція та навчальна платформа

Матеріали для Вероніки (@veronika_logistics) — запуск 7-го потоку курсу
«Міжнародна логістика з нуля».

## Сторінки

- `index.html` — комерційна пропозиція, готова сторінка
  (відкривається у браузері як є)
- `propozytsiya.html` — той самий вміст без обгортки `<html>/<head>`,
  для публікації як Artifact
- `platforma/index.html` — демоверсія навчальної платформи:
  кабінет учня з 8 модулями, панель адміністратора, тарифи,
  доступи на строк і оплати

Опубліковано через GitHub Pages:

- пропозиція — https://ouranus4.github.io/Veronika-Logistics/
- платформа — https://ouranus4.github.io/Veronika-Logistics/platforma/

Сторінки зв'язані: у пропозиції, у пункті «Навчальна платформа»,
є посилання на демо; у платформі в шапці — посилання назад.

## Про демо платформи

Вхід спрощений, без паролів: обираєш, ким зайти — учнем або адміністратором.
Стан (видані доступи, оплати, прогрес) зберігається в `localStorage` браузера
відвідувача, тому кожен бачить свою пісочницю. Кнопка «Скинути демо»
в панелі адміністратора повертає початковий стан.

Назви 8 модулів і уроків усередині — тимчасові заглушки до отримання
реальних матеріалів курсу. Структура даних лежить у константах
`COURSE`, `TARIFFS`, `STUDENTS` на початку `<script>` у `platforma/index.html` —
заміна контенту не потребує змін у розмітці.
